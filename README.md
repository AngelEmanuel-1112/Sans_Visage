# Sans Visage by PrivaQR

> Ropa que protege tu privacidad frente al reconocimiento facial.

## Descripción

Las cámaras de seguridad actuales con inteligencia artificial pueden grabar y reconocer el rostro de las personas. **Sans Visage** ("sin rostro" en francés) es un conjunto de playera y pantalón con un código QR que hace que la cámara se enfoque en el código y no en la cara, para proteger la privacidad del usuario.

## Marca y prenda

| | |
|---|---|
| **Marca** | PrivaQR |
| **Prenda** | Sans Visage (playera y pantalón) |

## Diseño

### Playera
- Código QR en la prenda.
- Imágenes recortadas con relieve hecho de cartón.

### Pantalón de mezclilla
- **Pierna derecha:** cadenas de plástico con botones que cruzan el muslo y terminan en botones de plástico color bronce.
- **Pierna izquierda:** imágenes recortadas.

## Materiales

- Tela de algodón (playera)
- Mezclilla (pantalón)
- Plástico (silicón, código QR, cadenas y botones)
- Cartón (relieves)
